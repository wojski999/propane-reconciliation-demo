# Propane reconciliation demo

A public demonstration of daily propane distribution checks using synthetic data.
The planned report highlights transactions needing attention and traces each
finding to its source. No real systems, client records or credentials are used.

**Current status: repository foundation only.** No reconciliation checks, KPIs,
business fixture generator or vendor integrations are implemented yet. See the
[approved specification](.ai/specs/2026-11-04-propane-reconciliation-demo.md).

## Run the foundation smoke sample

Requires Python 3.12 and Make. From a fresh clone:

```sh
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -e '.[dev]'
make check
propane-smoke --output artifacts/smoke.html
```

Open `artifacts/smoke.html` locally. It contains one synthetic marker generated in
an in-memory SQLite database and explicitly states that no audit was evaluated.
This command tests the packaging/SQLite/static HTML path; it is not the business
CLI planned in the spec. No API key, database server, browser automation or network
connection is needed after dependency installation. Existing files at the chosen
output path are replaced; filesystem errors return exit 1, usage errors exit 2.

CI runs the same `make check` and uploads `foundation-smoke-report`, generated by
the installed CLI E2E test. Tests cover all application lines and branches at 100%,
with independent unrounded gates. Ruff checks application, tests and check scripts.
